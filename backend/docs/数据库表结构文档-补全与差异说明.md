## 1. 遗漏表补全（原文档没写，实现需要）

### 1.1 `favorites` 收藏关系表 ★新增

与点赞分表（收藏和点赞是两套独立状态，F8 口径）。

```sql
CREATE TABLE IF NOT EXISTS favorites (
  user_id     BIGINT      NOT NULL,
  target_id   VARCHAR(36) NOT NULL,
  target_type VARCHAR(10) NOT NULL DEFAULT 'message',  -- message | comment
  created_at  BIGINT      NOT NULL DEFAULT 0,           -- 毫秒时间戳
  PRIMARY KEY (user_id, target_id),
  KEY idx_fav_target (target_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8;
```

### 1.2 `idempotency_keys` 幂等键表 ★新增

点赞/收藏防抖动：同一 `idemKey` 只允许成功处理一次，重复请求返回当前状态。

```sql
CREATE TABLE IF NOT EXISTS idempotency_keys (
  idem_key   VARCHAR(64) NOT NULL,
  user_id    BIGINT      NOT NULL,
  created_at BIGINT      NOT NULL,
  PRIMARY KEY (idem_key)
) ENGINE=InnoDB DEFAULT CHARSET=utf8;
```

### 1.3 `meta` 表的实现差异

原文档 §1.10 的 `meta` 元数据单行表**未单独建**，其职责并入 `settings` 表
（`current_period` 字段 + 新增 `sensitive_words` 敏感词 JSON 数组字段）。
若后续 GM 需要独立 meta（如演示数据版本号），再加表即可，不影响现有结构。

## 3. 实现差异说明

| 项 | 原文档 | 实际落地 |
| --- | --- | --- |
| 主键风格 | `resourceId` UUID 字符串 | 一致（messages/comments 用 VARCHAR(36)；users 用 BIGINT 自增） |
| 时间戳 | 毫秒 BIGINT | 一致（**全表统一 BIGINT**，含 sessions/likes/favorites） |
| 密码 | PBKDF2 加盐 | 一致，格式 `pbkdf2:10000:<saltHex>:<hashHex>`（SHA1，160 位） |
| 索引 | — | 补充：`idx_msg_period_pub(period,is_public)`、`idx_msg_pub_time(is_public,created_at)`、`idx_cmt_msg_time(message_id,created_at)` |
| 盲盒留痕 | `blindbox_replies` | 一致，`reply_id` 即评论 resourceId，`real_owner_id` 不经任何接口出口 |
| 敏感词 | 常量字典 | 存 `settings.sensitive_words`（JSON 数组，GM 可改，本期词库：加微信/代考/办证/刷单） |

## 4. 种子数据状态

- 6 个用户（`13800000001`~`13800000006`，密码统一 `abc12345`，PBKDF2 哈希）；
- 8 条留言（含 1 条私密帖 m-secret-2026-0008 用于可见性测试）；
- 13 条评论（含两级树和 1 条盲盒匿名回复 c-0012）；
- 12 条点赞、3 条收藏、1 条盲盒留痕、1 行 settings。

## 5. 迁移避坑（联调时实际踩过的）

1. **tinyint(1) 会被 MySQL 驱动映射成 Boolean**：读出口层必须兼容 Boolean→int，否则 is_public/edited/is_new 恒为默认值；
2. **时间列全部 BIGINT**：写入口用 `setLong(毫秒)`，不要 `setTimestamp`（会报 Data truncated）；
3. **GET 查询参数中文**：Tomcat 6 必须在 server.xml Connector 加 `URIEncoding="UTF-8"`，否则搜索词乱码（已配好）；
4. `INSERT IGNORE` 的 affected rows 可直接用作幂等判断（0=重复，1=首次）。
